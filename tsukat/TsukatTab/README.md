# TsukatTab 2.0

- Paper 26.2
- Java 21+ (server Java 25 supported)
- Resource pack is external via ResourcePackManager only.
- Vanilla player profiles are not replaced, so skin heads stay visible.
- Rank badges use the `tsukat:tab` custom font.
- Play streak: +1 day per 24 hours online; if offline for more than 12 hours, streak resets.
- Persistent streak data: `plugins/TsukatTab/streaks.properties`.
