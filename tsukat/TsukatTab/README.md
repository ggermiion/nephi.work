# TsukatTab 2.1 Compact

Current production direction:

- Paper 26.2
- Resource pack only through ResourcePackManager
- no embedded resource pack in JAR
- compact 9px rank icons instead of large badge ribbons
- compact TSUKAT logo
- vanilla player profiles are preserved so skin heads are not replaced by the plugin
- play streak: +1 day per 24 hours online
- streak is reset after more than 12 hours offline
- persistent streak data: `plugins/TsukatTab/streaks.properties`

Production artifacts:
- `TsukatTab-2.1.0-RSPM-COMPACT.jar`
- `TsukatTab-ResourcePack-2.1.0-COMPACT.zip`

The old 2.0 oversized ribbon UI is deprecated.
